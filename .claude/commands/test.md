# Test

Run the test suite using Vitest.

## Run all tests

```bash
npm test
```

## Watch mode (re-runs on file changes)

```bash
npm run test:watch
```

## Run a specific test file

```bash
npm test src/components/__tests__/TodoInput.test.tsx
```

## Run tests matching a pattern

```bash
npm test -- -t "should add"
```

## Visual UI for debugging

```bash
npm run test:ui
```

# Run tests without coverage (should work fine)

npm test
